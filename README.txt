1000 Word Philosophy Scraper

Web app: https://dominickrobinson.github.io/1000-word-philosophy-scraper/

Use Choose folder, then Download new articles. Images are downloaded when possible; failed images are omitted.
An empty folder starts the whole collection. Existing progress in
philosophy-library.txt prevents repeat essay downloads. Sync that TXT file
and your EPUBs together before switching devices.

Chrome/Edge on desktop save directly to the selected folder. Other browsers
use a ZIP export; extract its EPUBs and TXT record into your library folder.
This project is web-only; there are no native app downloads or releases.

New essay filenames contain titles only, without date prefixes. Existing
downloads are still recognized. Each run refreshes All Essays.epub with
By Category and By Date sections. Titles link to the original website;
find downloaded essays by searching for their titles.

README.md contains usage, development and deployment details.
No private signing credentials or downloaded essay collection belong in Git.
