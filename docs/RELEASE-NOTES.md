- Generate All Essays.epub with By Category and By Date navigation, plus All Essays.html with local links to downloaded files.

Direct links between separate EPUBs depend on the reader and a known file location. Android-generated indexes use those locations when available; browser-generated EPUB indexes use website links. The companion HTML index uses neighboring EPUB filenames. Supernote cross-file links are unverified.

The APK uses the existing signing key and can update previous installations. Android 8+; no Google Play services required. Physical Supernote testing is still needed. Automated tests cover the reported failures, saved history, old aliases and filenames, master indexes, images, citations and ZIP export.

SHA256SUMS.txt is a public download-integrity checksum, not a signing secret. GitHub also adds automatic source archives.
